# @standupcamedy — Analytics HQ

Live growth tracker, trend intelligence & AI strategy dashboard for Instagram comedy creator **@standupcamedy**.

## 🚀 Deploy to Vercel (3 Steps)

### Step 1 — Upload to GitHub
1. Create a new GitHub repository (e.g. `standupcamedy-analytics`)
2. Upload all files from this folder into the repo

### Step 2 — Connect Vercel
1. Go to [vercel.com](https://vercel.com) → New Project
2. Import your GitHub repository
3. Vercel auto-detects Vite — click **Deploy**

### Step 3 — Done!
Your live URL will be: `https://standupcamedy-analytics.vercel.app`
